OPT Employer Checker

Free, unofficial. Not affiliated with DHS or USCIS.

A free Chrome extension that shows E-Verify and H-1B information next to employers on LinkedIn job pages, so F-1 and STEM OPT job seekers can spot problems before they accept an offer.

Please read: this tool cannot guarantee that an employer will sign an I-983, and it is not legal advice. Your DSO is the authority. Ask your DSO.

What you see on LinkedIn

E-Verify: enrolledH-1B 12
E-Verify chip
Says whether the employer has an enrollment on file, whether it is open or ended, and when it started. Click the chip for details.
H-1B chip
Shows how many H-1B petitions the employer filed in recent fiscal years, from the USCIS H-1B Employer Data Hub.
"Not found" is not a verdict
It only means the name was not in our data. It does not mean the employer is not enrolled. A name must match exactly after normalizing, so a similar-looking name is never shown as a match.
"Couldn't check"
Shown when the data could not be loaded, for example when you are offline. It never means "not enrolled".

Data and sources

  • E-Verify: the public E-Verify employer search data. We cover about three quarters of E-Verify employers, so an employer can be missing.
  • H-1B: the USCIS H-1B Employer Data Hub.
  • Data date: loading…. The extension always shows the data date next to what it tells you.
  • Some E-Verify enrollments cover only federal-contract work. An enrollment on file may not apply to the job you are applying for.

Privacy

  • The extension reads the company name shown on the LinkedIn job page you are viewing, inside your browser. It only runs on linkedin.com.
  • Company names never leave your browser. The name is normalized and hashed on your computer, and only the first 3 characters of the hash are used to request a data file. That file is shared by hundreds of employers, so the data site cannot tell which employer you looked at.
  • The data files are static files hosted on GitHub Pages. Like any website, GitHub can see your IP address and which data file was requested. We do not run a server, an account system, analytics, advertising or tracking, and we do not collect, sell or share personal data.
  • Downloaded data files are kept in your browser's own cache so lookups are fast. They contain public employer data only. Nothing about you or your searches is stored.
  • The extension asks for no browser permissions beyond reading LinkedIn pages and fetching these data files.
